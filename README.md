# Project_Airline-Management_Info

Grup: Kashish Chand, Joseph Brando Quizhpe, Laura Verdugo i Ferran Arbusà

# Versió 1
Aquesta entrega desenvolupa el codi en Python per a la gestió d'informació d'aerolínies. El sistema permet estructurar les dades d'una companyia aèria —nom, flota d'avions i operacions de vol— mitjançant la creació de les classes 'Aircraft', 'Flight' i 'Airline', incorporant la lectura i persistència de dades des de fitxers de text. El projecte culmina amb la implementació d'una interfície gràfica d'usuari (GUI) construïda amb Tkinter, que integra visualitzadors de dades i un gràfic interactiu generat amb Matplotlib per analitzar la distribució de vols en l'aire per cada hora del dia.
